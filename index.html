How it works

  1. Crop the centre of the frame, shrink to 64×64, convert to gray.
  2. Histogram equalization spreads the brightness values, which reduces lighting effects.
  3. Local Binary Pattern: each pixel is compared with its 8 neighbours, giving an 8-bit code.
  4. Split into a 4×4 grid, count the codes in each cell, and join the 16 histograms into one feature vector.
  5. Compare with each saved template using the chi-square distance. The smallest distance wins; above the threshold the answer is “not recognized”.

Try the limits: enroll in good light, then identify again with dim light, a tilted head, or glasses. The distance rises because nothing here learns to ignore those changes. That is why modern systems use ML.
